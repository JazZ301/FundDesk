# 基金看板跨平台方案

更新于 2026-11-26。目标是用一套代码覆盖 Windows 10 与 macOS，功能与 Swift 版 v0.3.29 对等；两版此后独立演进。

## 技术栈

| 层 | 选择 |
| --- | --- |
| 桌面壳 | Tauri 2（Windows: WebView2 / macOS: WKWebView） |
| 内核 | Rust + `rust_decimal` + `chrono` / `chrono-tz` |
| 前端 | React 18 + TypeScript + Vite |
| 表格 | TanStack Table + dnd-kit |
| 图表 | ECharts |
| 状态 | Zustand |
| 打包 | NSIS（Windows，按用户安装）/ DMG（macOS 通用二进制） |
| 更新 | `tauri-plugin-updater` + minisign |

## 分层

```
crates/core/   纯 Rust：模型、收益口径、行情解析、持久化、备份
src-tauri/     托盘、窗口、调度器、IPC
src/           React 界面
```

硬性规则：

- 金额计算只在 Rust 内完成，前端只做格式化。
- 行情轮询在 Rust 侧运行，窗口隐藏后继续刷新，托盘标题直接由 Rust 更新。
- 所有网络请求在 Rust 侧发出，便于设置 `Referer`、解码 GBK、绕过 CORS。

## 兼容口径

- Swift `Date` 使用 2001-01-01 纪元秒，`SwiftDate` 负责换算。
- Swift `Decimal` 以裸 JSON 数字写入，经 `RawValue` 保持精度，不经过 `f64`。
- 可选字段缺省时不写 `null`，与 Swift 合成 Codable 一致。
- 字段名必须逐字对齐，注意 `hiddenFundColumnIDs` 这类缩写。
- 已用 791 KB、17 只基金的真实看板验证：解码 → 重编码 → 再解码，排序后逐字节一致。

## 双端交互

| 能力 | macOS | Windows 10 |
| --- | --- | --- |
| 常驻入口 | 菜单栏图标 + Dock | 通知区域托盘 |
| 快览 | 无边框浮层 | 托盘左键浮层 |
| 关闭窗口 | 隐藏并驻留 | 隐藏并驻留 |
| 上证指数 | 状态栏文字 | 托盘提示 + 浮层 |
| 自启 | LaunchAgent | 注册表 Run 项 |

已知差异：Tauri 的状态栏标题只支持单色，原生版的涨红跌绿需要另行渲染图片或接入 `objc2`，安排在界面阶段处理。

## 阶段

| 阶段 | 内容 | 出口条件 |
| --- | --- | --- |
| P0 | 壳、数据往返、行情、图表、托盘 | 双端能跑通最小链路 |
| P1 | Rust 内核移植 | 与 Swift 的 golden 样本逐字段一致 |
| P2 | 行情与调度 | 缓存、退避、后台刷新完整 |
| P3 | 界面迁移 | 主表、详情、行情中心、期货、观察、设置 |
| P4 | 桌面集成 | 托盘/浮层、单实例、自启、文件选择 |
| P5 | 数据迁移 | v1–v4 备份、CSV、恢复点双向验证 |
| P6 | 打包发布 | 签名、公证、自动更新、CI 双平台 |

截至 2026-11-27，P0–P3 与 P6 的打包部分已完成：独立名称/标识、旧数据迁移、
macOS universal DMG、Windows x64 NSIS 和图标均已验证。Developer ID 签名、
公证和 Windows 正式代码签名仍等待证书材料。

## 公开发布前置项

- 选择并添加 LICENSE。
- Apple Developer ID + 公证；Windows 代码签名。
- 数据来源合规确认，明示延迟与非投资建议。
- 隐私说明：本机存储、无账号、无遥测。

## 构建注意

- release 必须带 `custom-protocol` feature，否则仍会访问 devUrl。
- 使用 `lto = "thin"`；fat LTO 在当前 macOS 工具链会产出损坏的 proc-macro dylib。
- Windows x64 安装包已在本机 Parallels 的 ARM64 Windows 上构建并通过模拟运行；
  正式发布仍建议由 CI 生成并签名。
