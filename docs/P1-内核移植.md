# P1 内核移植记录

日期：2026-11-26（北京时间）

## 范围

把 Swift `FundCore` 中与界面无关的规则移植到 `crates/core`，并以 Swift 原实现生成的样本做跨语言比对。

| 模块 | Rust 文件 | 对应 Swift |
| --- | --- | --- |
| 买卖流水、成本与已实现收益 | `src/journal.rs` | `PositionJournal.swift` |
| 收益、组合汇总、估值健康度 | `src/metrics.rs` | `Models.swift` |
| 交易日、归属日、估值时效 | `src/clock.rs` | `MarketClock` |
| CSV 导入导出 | `src/csv.rs` | `HoldingCSV.swift` |
| 备份 v1–v4、恢复点 | `src/backup.rs` | `Persistence.swift` |
| JSON 备份和 CSV 导入预览 | `src/import.rs` | `ImportPreview` |
| 搜索 | `src/search.rs` | `FundSearch.swift` |
| MACD、布林带、滚动分位 | `src/observation.rs` | `ObservationAnalysis.swift` |
| 期货横轴刻度 | `src/futures_axis.rs` | `FuturesAxis.swift` |
| 列序、标签序、行拖动 | `src/board_ops.rs` | `Board` 扩展 |

## 跨语言 golden

`tools/golden/main.swift` 直接编译基金看板的 `FundCore` 源码，读取共享场景
`crates/core/tests/fixtures/scenario-metrics.json`，输出
`crates/core/tests/fixtures/golden.json`。Rust 测试重算同一场景并逐项比对。

覆盖：

- 上海时区归属日、午休与盘中窗口、估值新鲜度；
- 9 只基金的已披露/盘中/货币/跨境/估值基准错位/过期/缺估值分支；
- 组合金额、当日收益、覆盖率、排除原因、估值健康度；
- 买入、加仓、赎回、现金分红后的份额与成本，以及反向还原基准持仓；
- CSV 字节级导出、解析、分类恢复；
- 搜索的代码/名称/拼音/简拼匹配；
- MACD 指标、信号文案、布林带与 250 日分位；
- 期货日盘与夜盘横轴刻度；
- v2 备份在 Rust 中解码再编码。

重新生成：

```sh
bash scripts/regenerate-golden.sh
```

需要本机存在同级目录 `../fund` 的 Swift 源码；它只用于生成测试样本，不参与 Rust 构建。

## 精度口径

- 金额全部使用 `rust_decimal`，不经过 `f64`。
- `rust_decimal` 为 96 位尾数（约 28–29 位有效数字），Swift `Decimal` 为 38 位。
  除法结果在 1e-9 相对误差内比对；实际基金净值与金额只用到 4 位小数。
- 反向还原成本时按 Swift 规则四舍五入到 8 位，使用银行家舍入。
