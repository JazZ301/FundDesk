配套：

- `cache.rs`：`research-v1/` 分块 JSON 缓存，原子写入，记录保存时间。
- `scheduler.rs`：正式净值 20 分钟 / 失败 4 分钟；估值失败后取 30 秒与 4 倍间隔的较大值。
- `market.rs`：指数交易时段、午休压缩位置、轴线刻度、周/月 K 聚合。

## 口径说明

- 新浪 `worth_rate` 与 `growthrate2` 是小数，统一乘 100 后入库。
- 东财净值接口的 `FundType == "005"` 视为货币基金：使用万份收益，`LJJZ` 作为七日年化。
- 跨境基金凌晨估值归属上一标的市场交易日。
- 腾讯指数成交量为累计值，按相邻分钟做差。
- 东财 `push2` / `push2delay` / `push2his` 在当前网络整域空响应；涨跌家数自动退新浪
  全市场快照，资金流自动退新浪 48 个行业汇总，最后才退腾讯成交额。
- 新浪备用资金流是行业汇总的近似口径，仅提供主力净流入；超大单/大单/中单/小单在备用
  模式下禁用，不用 0 或推算值伪装原始分项。
- 期货五日接口若无有效价格，自动退最近五个日 K 收盘。
- 自定义期货代码只接受字母数字，统一转大写；自选写入 `futures-watchlist.json`，
  不混入 Swift 版 `board.json`。
