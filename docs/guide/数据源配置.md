# 数据源配置

安装包自带一份默认接口配置，资源文件为 `src-tauri/resources/data-sources.json`。首次启动时，如果本机数据目录还没有 `data-sources.json`，应用会自动复制这份配置，下载后即可使用。接口地址不写死在程序代码里，仍可通过设置窗口替换为自己的配置，或恢复内置默认。

## 文件位置

- macOS：`~/Library/Application Support/FundDeskDesktop/data-sources.json`
- Windows：`%APPDATA%\FundDeskDesktop\data-sources.json`
- 可用 `FUND_DESK_SOURCES_FILE` 指向其他配置文件，便于测试或多环境切换。

也可以直接粘贴 JSON 到设置窗口。保存时会先校验，再写入文件并立即应用。

已有本机 `data-sources.json` 时不会自动覆盖，升级不会改动用户配置。点击「恢复内置默认」会用安装包中的配置覆盖当前文件；「清空配置」会写入空配置，重启后保持为空。

## 字段

| 字段 | 说明 | 是否必需 |
| --- | --- | --- |
| `version` | 配置版本，当前为 `1` | 是 |
| `label` | 配置名称，最多 80 个字符 | 否 |
| `eastmoney.fund` | 基金目录、净值脚本、pingzhongdata | 是 |
| `eastmoney.fundApi` | 基金历史净值接口 | 是 |
| `eastmoney.fundMobile` | 基金档案、披露、经理接口 | 是 |
| `eastmoney.fundSuggest` | 基金搜索接口 | 是 |
| `eastmoney.fundF10` | 历史净值请求的 Referer 来源 | 是 |
| `eastmoney.data` | 板块资金流和行情 Referer | 是 |
| `eastmoney.push2` | 东方财富实时行情 | 是 |
| `eastmoney.push2his` | 东方财富历史/分时行情 | 是 |
| `eastmoney.push2delay` | 东方财富延时行情 | 是 |
| `sina.finance` | 新浪 Referer | 是 |
| `sina.hq` | 新浪指数、期货快照 | 是 |
| `sina.stock` | 新浪基金估值 | 是 |
| `sina.stock2` | 新浪外盘期货分时/日线 | 是 |
| `sina.vip` | 新浪全市场快照和行业资金流 | 是 |
| `tencent.qt` | 腾讯指数和个股报价 | 是 |
| `tencent.ifzq` | 腾讯分时 | 是 |
| `tencent.portal` | 腾讯 Referer | 是 |
| `yahoo.query1` | 可选的美股指数分时源；留空时回退东方财富 | 否 |
| `http.userAgent` | 请求标识，默认 `FundDeskDesktop/1.0` | 否 |

所有 URL 必须使用 HTTPS；只有 `localhost`、`127.0.0.1`、`::1` 允许 HTTP。地址不能包含用户名、密码、查询参数或片段。字段可以是带路径前缀的反向代理地址，应用会拼接已知路径。

配置文件上限为 64 KB；`http.userAgent` 最多 200 个字符且不能包含控制字符。

## 安全与分发

- 只使用你信任的配置。配置决定净值、指数和估值数据来自哪里，错误数据可能误导投资判断。
- 不要把账号、密码、API Key 或带登录态的 URL 写进公开配置。
- 内置配置使用公开第三方接口，可能被限流、调整或停止服务；应用不保证长期可用，也不会自动切换未声明的来源。
- 自行分发配置时建议同时提供来源说明、更新日期和版本号；有条件时增加签名或 SHA-256 校验。
- 配置化不改变数据授权。使用未授权接口仍然可能违反来源网站条款；商业化和公共代理需要单独取得授权。
- 不要把配置地址写成可执行脚本，也不要在配置中要求关闭系统安全设置。
