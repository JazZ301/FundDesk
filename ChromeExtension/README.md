# 基金看板 Chrome 扩展

适用于 Windows 和 macOS 的 Chrome 130 或更新版本。

1. 解压 ZIP。在 Chrome 地址栏打开 `chrome://extensions`。
2. 启用「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择包含 `manifest.json` 的 `ChromeExtension` 文件夹。通过 Chrome 的扩展菜单可以把「基金看板」固定到工具栏。
4. 点击工具栏图标查看上证指数与分时，点击「打开完整看板」查看自选及持仓。

## 从 Mac 原生版迁移

在原生基金看板导出 v4 完整 JSON 备份。打开 Chrome 版的「设置」，在「备份与恢复」下选择 JSON 文件，核对预览后确认恢复。恢复会把原 Chrome 看板保存为恢复点。可通过 v4 完整备份在两台电脑间手动迁移。

扩展把自选、持仓、流水、设置、观察资料和行情缓存保存在当前 Chrome 配置文件。不同 Chrome 配置文件各自保存数据。更新本地扩展时，保留原文件夹位置并在扩展页重新加载。如需卸载或更换安装目录，先导出备份。

## 行情

基金、指数、持仓个股、期货和板块行情在扩展内直接请求对应行情提供方。看板打开时按设置刷新。当前实测环境下，东方财富两市资金流及涨跌家数接口连接失败。该区域会标明缓存或暂不可用，成交额可使用腾讯来源。

本地扩展无需运行 Mac 原生版或搭配桌面程序。工具栏快览和完整看板共用本地数据。
